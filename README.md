# Transactional-Text-Digital-Formative-Assessment-
Scan the QR code or open the link to do the quiz. Write your full name and class first. Choose the best answer (A, B, C, or D) for each of the 10 questions. Choose only one answer. After each answer, read the feedback to learn why. When you finish, press "See my score." You can do this quiz only once, so work carefully.
